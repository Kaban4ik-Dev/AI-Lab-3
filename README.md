# Лабораторная работа №3 по предмету Искусственный интеллект

Для использования в Microsoft Visual Studio Code:
1. запустите в репозитории Python (лучше venv);
2. установите все зависимости из requirements.txt;
3. используйте готовые конфигурации отладки для запуска необходимых скриптов.

Для использования без Microsoft Visual Studio Code:
1. запустите в репозитории Python (лучше venv);
2. установите все зависимости из requirements.txt;
3. используйте команды python для запуска необходимых скриптов.
